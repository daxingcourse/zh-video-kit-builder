# zh-video-kit-builder：我的內容部製作器

[語剪室（zh-video-kit）](https://github.com/daxingcourse/zh-video-marketplace)的姊妹 skill，給 Claude 或 Codex 桌面版使用。回答幾個問題（風格、定位、規模），它會帶你整理出自己的口播影片內容系統：定位卡、大綱、圖文教學頁，以及一份屬於你自己的 skill。剪片與雙語字幕交給語剪室。

- 事實由你提供，沒說的會留【待補】，不編造、不保證任何成效。
- 註冊、登入、付款、發布都由你自己操作。
- 資料只存在你自己的電腦。

## 安裝

在桌面版裡，把下面這句貼給 Claude：

> 請幫我安裝這個 skill：https://github.com/daxingcourse/zh-video-kit-builder ，資料夾是 zh-video-kit-builder。每個步驟都先告訴我要做什麼。

Codex：用 `$skill-installer` 從這個 GitHub 連結安裝，裝完若沒看到請重新啟動。

安裝位置與指令會隨軟體版本不同，作者尚未在每個版本實測，請以各軟體官方說明為準。

## 使用

裝好後說：「我想做自己的一份，開始製作」。
