# 產出自我檢查

交給使用者之前，逐項檢查，並如實回報結果（沒過的也要說）。

## 內容

- [ ] 每一個事實（經歷、案例、數字、價格）都能在訪談紀錄找到；找不到的已改成【待補】
- [ ] 沒有「保證」「一定」「百分之百」「月入」「穩賺」這類說法
- [ ] 沒有複製他人課程、講義、銷售頁的原文
- [ ] 受規範領域已加「用語請專業人士確認」
- [ ] 沒有放入密碼、金鑰、付款資料、他人的個資
- [ ] 操作步驟凡未實測的，都標「未實測」

## 教學頁

- [ ] 淺色與深色都看得清楚，文字對比足夠
- [ ] 手機寬度沒有橫向捲動
- [ ] 示意圖都標「示意圖，非實際畫面」
- [ ] 需要真實畫面的地方，留了空框與說明，沒有假造
- [ ] 標題是名稱，不是整句說明
- [ ] 頁尾有不保證成果的聲明

## 他自己的 skill

- [ ] `name` 與資料夾名一致
- [ ] `description` 有觸發詞
- [ ] 有「一律遵守」段落
- [ ] 流程每階段都有讓使用者確認

## 回報格式

「做了什麼」「還缺什麼（待補清單）」「沒驗證的地方」「建議你自己先看哪三處」。
