# 產出格式

## 資料夾

```
my-kit/
  00_訪談紀錄.md
  01_定位卡.md
  02_大綱.md
  pages/
    00_目錄.html
    01_….html
  my-skill/
    <skill-name>/
      SKILL.md
      references/
```

## 01 定位卡（一頁）

```
# 定位卡
- 一句話：我幫【誰】在【什麼情境】做到【什麼】
- 目標學員：（程度、現況、卡點，取自訪談）
- 我能提供的事實：（經歷、案例、證照；沒有就寫「目前沒有」）
- 我的做法與差異：（用他自己的話）
- 說話方式：（語氣、一定要用／不要用的詞）
- 還缺的事實：【待補】清單
- 提醒：（受規範領域加「用語請專業人士確認」；一律加「不保證成效」）
```

## 02 大綱

每個單元一段：

```
## 單元 N｜標題
- 學完你能：我能……（1 到 3 句，來自訪談第 7 題）
- 內容重點：（3 到 5 點，只放他說過的做法）
- 練習：（一個學員能實際做的小作業）
- 他要補的事實：【待補】
- 還沒驗證的步驟：（操作類步驟請標「未實測」）
```

## 圖文教學頁規格

- 單一 `.html` 檔，用瀏覽器直接開，不依賴外部腳本。
- `<title>` 是名稱，不是句子。
- 顏色全用 CSS 變數，淺色與深色兩套（見 `style-palettes.md`），`body` 要有明確背景。
- 手機寬度（約 400px）可閱讀，不出現橫向捲動；左右留至少 16px。
- 每個步驟：編號、標題、做什麼、你會看到什麼、卡住怎麼辦。
- 示意圖：內嵌 SVG，顏色用變數，標「示意圖，非實際畫面」。真實畫面留空框與說明，由使用者自己截圖放入。
- 結尾放「檢查清單」與「卡住了怎麼辦」。
- 頁尾固定寫：「內容依作者個人經驗整理，不保證任何成果。」
- 內容只能取自訪談紀錄與大綱。

## 他自己的 skill（SKILL.md）

```
---
name: <英文小寫與連字號>
description: 一到兩句說明做什麼；要包含使用者會說的觸發詞
---

# 標題

目標與界線（不編造、不保證、事實由使用者提供）
流程（一步一步，每階段讓使用者確認）
一律遵守
```

要求：

- `name` 與資料夾名稱一致。
- 不寫死使用者的個人隱私（電話、信箱、金鑰）。
- 把「他的定位、語氣、不能說的詞」放進 `references/`，不要散在流程裡。

## 怎麼安裝他自己的 skill

- 這份只是說明，**這些路徑與指令我們沒有在每個版本上實測**，請使用者以所用軟體的官方說明為準。
- Claude：把 skill 資料夾放進該軟體讀取技能的位置，或放進 GitHub 倉庫後請 Claude 依連結安裝。
- Codex：把 skill 資料夾放到 Codex 的技能目錄，或用 `$skill-installer` 從公開的 GitHub 連結安裝；裝完若沒看到，重新啟動 Codex。
